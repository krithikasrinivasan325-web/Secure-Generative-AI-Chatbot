# 🛡️ Securing a Generative AI Chatbot System Using SASE, JEM, and DeepFool for Adversarial Detection

## 📌 Project Overview

This project presents a secure Generative AI chatbot system designed to protect users against modern cyber threats such as prompt injection, adversarial attacks, and unauthorized access. The application integrates Secure Access Service Edge (SASE), Just Enforcement Mechanism (JEM) Authentication, and DeepFool-based adversarial detection to ensure secure and reliable AI interactions.

The chatbot is developed using the Flask framework and integrates Google's Gemini API for intelligent response generation while implementing multiple layers of security.

---

## 🎯 Objectives

- Develop a secure AI-powered chatbot.
- Prevent adversarial attacks using the DeepFool algorithm.
- Implement secure user authentication using JEM.
- Secure communication through SASE architecture.
- Detect and mitigate malicious prompts.
- Provide a responsive and user-friendly web interface.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/yourusername/SecureChat-SASE-JEM-DeepFool.git
```

### Navigate to the Project

```bash
cd SecureChat-SASE-JEM-DeepFool
```

### Install Dependencies

```bash

```

### Run the Application

```bash

```

