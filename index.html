Technical Implementation

  • SASE (Secure Access Service Edge): Pattern-based security check that scans inputs for harmful content like SQL injection attempts, code execution patterns, and credential harvesting.
  • JEM (Joint Energy-based Model): Uses an energy function to identify statistical anomalies in inputs that might represent novel attacks not covered by pattern matching.
  • DeepFool Algorithm: Creates gradient-based perturbations to test how a slight modification affects the model's output. Large changes indicate potential adversarial examples designed to manipulate the AI.
  • Text Embedding: Uses BERT to create vector representations of text that can be analyzed by the security models.
  • Layered Protection: Security checks must all pass sequentially before the input reaches the Gemini API, ensuring comprehensive protection.
